# go-workload-identity 🐹

> 🧭 Kubernetes workload identity for gRPC services: verify projected ServiceAccount tokens and enforce a per-method caller allow-list.

## 📦 Install

```bash
go get github.com/Bugs5382/go-workload-identity
```

task build    # go build ./...
